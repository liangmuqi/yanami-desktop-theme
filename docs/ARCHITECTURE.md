# 实现与边界

```text
现有固定图标 → ThemeEntry（写入启动请求）
                      ↓
              现有后台程序 → 官方客户端（一次激活）
                      ↑
当前用户后台任务 → 本机 CDP 连接 → 主题与开屏
                                    ↓
                         原生只读账户额度请求
```

`worker.cjs` 只连接回环地址，并核对监听端口是否属于原客户端的单一主进程。对于没有调试参数的普通启动实例，只记录未接入状态，不关闭、隐藏、重启或重新激活客户端。旧恢复脚本已停用。`ThemeEntry` 只写入一次启动请求；后台程序监听请求，使用稳定的应用包标识激活客户端。每个请求仅处理一次；启动与主题连接都由独立后台完成，客户端自身负责单实例和窗口唤回。

启动时及连接失效后，`client-binding.cjs` 通过系统已注册的官方商店包重新解析客户端路径，验证包身份和签名再原子更新配置；保留端口等已有设置。失败时不启动恢复动作。连接失效期间的版本检测间隔为 30 秒。

主题使用独立 Shadow DOM，并仅为原生主区域预留右侧空间。全屏宿主默认不截获输入；人物、设置和气泡局部可交互。窄窗口收起人物。

GSAP 负责读取既有开屏编排的静态姿态，主要进场与衔接由 Web Animations API 运行。原生输入区的准备检查与开屏并行，输入可用后检查短暂稳定状态；3.5 秒准备预算从动画开始计时，不在动画结束后重新等待 3.5 秒。未就绪时仍有上限退出和 Esc 跳过，避免装饰长期挡住页面。

真实额度通过客户端已有的 `account/rateLimits/read` 只读请求取得。预览页面不连接该通道，使用明确标注的演示数据。

不会修改官方安装目录、签名、登录信息或聊天数据库。没有原版客户端的代码或修改后的 app.asar 随项目分发。CDP 并非官方主题扩展接口，兼容风险见已知问题。
