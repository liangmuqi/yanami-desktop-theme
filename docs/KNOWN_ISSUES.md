# 兼容性与已知问题

## 发布状态

这是 `v0.1.0-alpha.1` 实验性整理版，不是官方扩展。开发环境为 Windows x64；已在原机从官方商店包 `OpenAI.Codex 26.1016.6573.0` 更新至 `26.1016.8120.0` 后验证路径自动重绑、主题恢复及开屏重播衔接。源码检查、离线演示和部分原机接入测试不等于所有机器上的端到端兼容保证。

## 已知限制

**安装暂停：**统一启动入口已收到卡死反馈，尚未查明原因。安装脚本暂不执行安装，直到完成修复与实际启动验证。

1. **启动方式已改为单次激活，冷启动待实测。** 旧的“普通启动后关闭重开”机制已从后台移除。现有窗口唤回和连接失败不重启已检查；未完成完整退出后的实际验证前，不宣称首次打开问题彻底修复。
2. **仅替换后的入口加载主题。** 开始菜单固定项和 Nexus 必须指向统一入口。未替换的商店 / 搜索 / 任务栏入口冷启动可能没有主题，后台不会再强制重启它。
3. **原生加载时间不可由动画消除。** 开屏在输入区可编辑后再衔接，额外等待有上限；网络、账户连接和历史内容加载仍可能继续。
4. **客户端升级可能失配。** 版本路径变化会在官方包身份与签名校验后自动重绑；页面选择器、桥接协议和启动参数仍可能变化，需要重新验证兼容性。
5. **用量气泡只代表本地 Codex 共享额度。** 读取失败显示不可用，不猜测剩余量，不代替 ChatGPT 各模型限额。
6. **仅当前用户后台接入。** Windows Script Host、脚本策略、任务计划或本机端口被限制时可能无法工作。
7. **不支持不同平台的客户端安装。** 浏览器演示可独立运行，实际桌面接入目前只面向 Windows。

## 故障排查

| 现象 | 先检查 |
|---|---|
| 完全无主题 | 后台任务是否运行；官方客户端是否升级；是否同时安装了其他主题引擎 |
| 第一次消失、第二次可打开 | 记录入口和时间；这是已知问题，不要反复强制启动多个实例 |
| 动画结束后仍加载 | 观察原生输入区能否编辑、是否有客户端连接错误；本项目不会无限延长开屏 |
| 人物不见了 | 窗口是否太窄；是否关闭了“显示八奈见”；本地素材是否存在 |
| 气泡没有额度 | 账户连接是否正常；等待后刷新；不要提供账号密码或 Token |
| 卸载后仍有外观 | 先完整退出客户端；注入内容仅存在于当前渲染器内存 |

反馈请包含：Windows 版本、客户端版本、主题版本、使用入口、是否完整退出、可复现步骤。请勿直接附上整个状态目录、账户信息或聊天截图。
